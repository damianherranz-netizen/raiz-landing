¿Qué es RAÍZ?

RAÍZ nace para acercar a quienes producen con quienes compran: un lugar donde el sector primario español se conoce, se contacta y trabaja de forma directa y transparente. Dos puertas, una misma idea: RAÍZ Partners para el trabajo entre profesionales, y RAÍZ para llevar el campo a casa.
